# 幼兒園學習指標

依六大領域與年齡查閱「幼兒園教保活動課程大綱」學習指標。使用純 HTML、CSS 與 JavaScript，無建置或套件安裝需求。

## 本機預覽

在專案目錄執行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4173/ 。請透過 HTTP 伺服器預覽，直接開啟 HTML 檔案可能無法讀取 JSON。

## 檔案

- `index.html`：頁面結構與對話框。
- `assets/styles.css`：配色、表格、手機卡片、列印與減少動態效果樣式。
- `assets/app.js`：資料呈現、年齡篩選、領域導覽與複製清單。
- `data/learning_indicators.json`：原始學習指標資料。
- `CNAME`：既有 GitHub Pages 自訂網域。

## 操作

桌面預設以表格比較所有年齡；860px 以下使用手機卡片，首次開啟預選 2–3 歲。切換年齡會同步其他領域的篩選。課程目標總覽可以展開，點擊目標即可跳至對應指標。

箭頭指標會展開前齡的完整描述，並使用目前年齡的代碼。點擊複製後，成功的指標會加入本次頁面的清單，同一指標不重複加入。底部的「已複製」可再次複製單項、全部複製或清空；清空需確認。清單在重新整理後重設。

資料讀取失敗時可以重新載入。複製優先使用 Clipboard API，並提供舊式瀏覽器及 iframe 的後備方式；瀏覽器與嵌入頁面的權限仍可能限制複製。

## 部署

可直接透過既有 GitHub Pages 設定部署，需一併保留 `assets/`、`data/` 與 `index.html`。改版不需要新增建置步驟。
