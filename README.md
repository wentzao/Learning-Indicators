# 幼兒園學習指標

依六大領域與年齡查閱「幼兒園教保活動課程大綱」學習指標。使用純 HTML、CSS 與 JavaScript，無建置或套件安裝需求。

## 本機預覽

在專案目錄執行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4173/ 。請透過 HTTP 伺服器預覽，直接開啟 HTML 檔案可能無法讀取 JSON。

## 檔案

- `index.html`：頁面結構與對話框。
- `assets/styles.css`：配色、表格、手機卡片、列印與減少動態效果樣式。
- `assets/app.js`：資料呈現、年齡篩選、領域導覽與複製清單。
- `assets/wentzao-logo.webp`：文藻品牌原圖，頁面以裁切容器隱藏底部中文。
- `data/learning_indicators.json`：原始學習指標資料。
- `CNAME`：既有 GitHub Pages 自訂網域。

## 操作

桌面預設以表格比較所有年齡。左側以單一玻璃面板整合文藻 Logo、頁面標題、領域與年齡篩選，捲動時整體停留在視窗內；視窗高度不足時側欄可獨立捲動。較窄的桌面將領域與年齡上下排列；860px 以下改為頂部的精簡品牌與篩選面板，使用手機卡片，首次開啟預選 2–3 歲。切換年齡會同步所有領域的篩選。領域選取狀態會隨閱讀位置更新，手機跳轉目標會避開頂部控制列。

背景採用接近白色的淺灰與淡綠色調。介面採用半透明玻璃、背景模糊、亮邊與柔和陰影，面板使用 24–28px 圓角；不支援背景模糊的瀏覽器會顯示實色背景。課程目標總覽可以展開，點擊目標即可跳至對應指標。

延續前齡的指標預設只顯示「⟶」，點擊箭頭可展開完整內容，也可用鍵盤操作。複製時仍使用完整前齡描述與目前年齡的代碼。點擊複製後，成功的指標會加入本次頁面的清單，同一指標不重複加入。底部的「已複製」可再次複製單項、全部複製或清空；清空需確認。清單在重新整理後重設。

資料讀取失敗時可以重新載入。複製優先使用 Clipboard API，並提供舊式瀏覽器及 iframe 的後備方式；瀏覽器與嵌入頁面的權限仍可能限制複製。

點選領域時立即選定目標，平滑跳轉期間保持選取狀態，捲動停止後才恢復依閱讀位置更新；連續點選會採用最後一次選擇。滑鼠滾輪、觸控或頁面捲動按鍵可中斷跳轉並接手瀏覽。

## 部署

可直接透過既有 GitHub Pages 設定部署，需一併保留 `assets/`、`data/` 與 `index.html`。改版不需要新增建置步驟。

AI 教案目前僅討論，未串接 API。未來如新增 AI 功能，API 金鑰應保存在後端環境變數，由後端驗證使用者、控制用量並呼叫模型；不要把金鑰放入本靜態網站。
